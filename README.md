# IMSC 2027

Responsive landing page for the 12th International Maritime Science Conference in Split, Croatia.

## Development

```bash
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

Page sections and their styles live in `sections/`. Shared components are in `components/`, typed display content is in `data/content.ts`, and theme tokens are in `styles/theme.css`.
